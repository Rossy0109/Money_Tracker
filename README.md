# Simple Money Tracker

A minimal, free, and deployable money tracker PWA.

## 🚀 Setup

1.  **Supabase Setup**:
    *   Create a project on [Supabase](https://supabase.com).
    *   Run the `supabase_schema.sql` (found in the root directory) in the Supabase SQL Editor to set up the tables.
    *   Enable **Email Auth** in the Authentication settings.

2.  **Configuration**:
    *   When you first open the app, it will prompt you for your **Supabase URL** and **Anon Key**.
    *   You can find these in your Supabase Project Settings under **API**.

3.  **Deployment**:
    *   **GitHub Pages**: Push this directory to a GitHub repo and enable GitHub Pages.
    *   **Vercel**: Run `vercel` in this directory to deploy instantly.

## ✨ Features
- **Mobile-First**: Designed to work perfectly on your phone.
- **PWA**: Can be installed on your home screen.
- **Free**: Uses free-tier services only.
- **Privacy**: Your data stays in your own Supabase instance.
