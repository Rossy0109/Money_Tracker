# Accounting Report UI Verification

- The authenticated dashboard displays the Bengali **ফিনান্সিয়াল অ্যাকাউন্টিং** overview with monthly income, expense, net profit or loss, account balance, receivables, and net financial position.
- The **মাসিক রিপোর্ট PDF** dialog presents a month selector, seven separate report types, a PDF download action, and a user-initiated **ইমেইল / WhatsApp-এ শেয়ার** action.
- The sharing action is intentionally user-initiated and opens the device/browser sharing flow only after the user chooses it.
