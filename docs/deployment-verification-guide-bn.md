# ডিপ্লয়মেন্ট ভেরিফিকেশন ও ব্ল্যাংক-প্রোফাইল টেস্টিং নির্দেশিকা

এই নথিতে Vercel প্রিভিউ এবং প্রোডাকশন এনভায়রনমেন্টে ডিপ্লয় করার পর অ্যাপ্লিকেশন ভেরিফিকেশনের ধারাবাহিক পদক্ষেপসমূহ উল্লেখ করা হলো।

---

## ১. ডিপ্লয়মেন্ট প্রি-ফ্লাইট চেক (Pre-flight Checks)

1. **বিল্ড ও এন্ট্রি পয়েন্ট চেক:**
   ```bash
   pnpm check:vercel-entry
   ```
2. **লোকাল ফুল রিগ্রেশন স্যুট:**
   ```bash
   ADMIN_ACCESS_PASSWORD=ci-regression-admin-password pnpm test
   ```
3. **টাইপচেক:**
   ```bash
   pnpm check
   ```

---

## ২. লাইভ ডিপ্লয়মেন্ট ভেরিফিকেশন ধাপসমূহ

### ধাপ ১: হেলথ চেক ও পাবলিক রাউট ভেরিফিকেশন
- ব্রাউজারে অথবা curl দিয়ে এপিআই হেলথ চেক করুন:
  ```bash
  curl -I https://<your-vercel-domain>.vercel.app/api/health
  ```
- স্ট্যাটাস `200 OK` হতে হবে। কোনো ডাটাবেস পরিবর্তন ঘটবে না।

### ধাপ ২: Google OAuth লগইন ভেরিফিকেশন
1. ব্রাউজার ইনকগনিটো মোডে `https://<your-vercel-domain>.vercel.app` ওপেন করুন।
2. **Google দিয়ে লগইন** বাটনে ক্লিক করুন।
3. Google Consent Screen সঠিকভাবে অ্যাপের নাম (`আমার হিসাব`) এবং ইমেইল স্কোপ প্রদর্শন করছে কিনা নিশ্চিত করুন।
4. অথেন্টিকেশন শেষে ড্যাশবোর্ডে রিডাইরেক্ট হওয়া যাচাই করুন।

### ধাপ ৩: ব্ল্যাংক প্রোফাইল ডেটা আইসোলেশন ও লেনদেন টেস্ট
1. নতুন ইউজারের ক্ষেত্রে ১৫টি ডিফল্ট ক্যাটাগরি স্বয়ংক্রিয়ভাবে লোড হচ্ছে কিনা দেখুন।
2. একটি টেস্ট লেনদেন যোগ করুন (যেমন: ৫০ টাকা নাস্তা খরচ)।
3. ড্যাশবোর্ডে মোট খরচ ও ব্যালেন্স সাথে সাথে আপডেট হচ্ছে কিনা যাচাই করুন।
4. **"ব্যাকআপ ও এক্সপোর্ট"** পেজ থেকে JSON ব্যাকআপ ডাউনলোড করে ফাইলটির শুদ্ধতা যাচাই করুন।
