# 📖 User Guide

Welcome to the Foot Print of Money! This guide explains how to manage your finances effectively.

## 🔐 Logging In
- Use the **Master Password** provided during setup.
- If deployed with Google Auth, use your Google Account.

## 💰 Managing Transactions
- **Add Income**: Select an income account (e.g., 'ঠিকাদারী আয়'), enter the amount, and choose a payment method.
- **Add Expense**: Select an expense account (e.g., 'দৈনিক বাজার'), enter the amount, and choose where the money was spent from.
- **Descriptions**: Add notes to remember specific details about a transaction.

## 📊 Dashboard Summary
- **Total Income/Expense**: View your daily totals.
- **Balance**: Your current net balance across all accounts.
- **Weekly Insight**: Track how much you've spent in the last 7 days.

## 🌍 Language Support
- Switch between **English** and **Bengali (বাংলা)** using the buttons at the top right of the dashboard.

## 💾 Backups
- The system automatically syncs data to your **Supabase** cloud instance.
- Administrative users can trigger a manual JSON backup to **Google Drive** using the integrated tools.
